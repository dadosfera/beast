# UI kit — Platform shell (default theme)

Illustrative composition of the Beast default theme in the layout the library is designed for: `nb-layout` with a fixed `nb-layout-header` (4.75rem, shadow), a `nb-sidebar` (16rem / 3.5rem compacted) holding an `nb-menu` with the Dadosfera module icons (coletar, explorar, catalogo, analisar, inteligencia, entrega, qualidade, controlar, workspaces), and an `nb-layout-column` on the `#f2f2f2` layout background with cards, tabs, tree grid, tags, progress bars and pagination.

Interactive: sidebar compacts via the menu button, tabs switch, context menus and header actions raise toasts, tree grid sorts/filters/expands, pagination pages.

**Disclaimer:** the `dadosfera/beast` repo ships the component library and theme, not the platform's actual screens. Content and layout here are placeholders to show the theme in use; replace with real product screens when available.
