NbTabset / NbRouteTabset: uppercase bold tabs (padding 1rem 2rem) with a .25rem primary underline.

```jsx
<Tabset tabs={[{id:'a',title:'Visão geral',content:<p>…</p>},{id:'b',title:'Esquema',badge:{text:'3',status:'primary'}}]} />
```

- `fullWidth` stretches tabs evenly. Tabs accept `icon`, `badge`, `disabled`.
