NbUser: avatar (picture or initials) with name and title.

```jsx
<User name="Ana Souza" title="Data Engineer" />
<User name="Ana Souza" onlyPicture shape="semi-round" badgeText="3" />
```

- `shape`: rectangle | semi-round | round (default). `color` sets initials background.
- sizes tiny…giant (medium 2.5rem).
