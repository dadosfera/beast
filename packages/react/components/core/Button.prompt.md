Beast/Nebular nbButton: filled, outline or ghost button in five sizes with status colors.

```jsx
<Button status="primary">Salvar</Button>
<Button appearance="outline" icon="plus-outline">Novo</Button>
<Button appearance="ghost" icon="trash-2-outline" />
```

- `appearance`: filled (default) | outline | ghost | hero.
- `status`: basic (default) | primary | success | info | warning | danger | control.
- `size`: tiny…giant (medium default, padding .6875rem 1.125rem). `shape`: rectangle | semi-round | round.
- Button text is Quicksand 700, never uppercase.
